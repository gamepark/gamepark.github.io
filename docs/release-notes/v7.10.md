# Release notes v7.10

## Help dialogs

- A help opened from another help shows a back icon, to return to the previous one.
- With `displayInParentItemHelp = true` in a Material Description, the items placed on a parent item are also displayed in the help dialog of the parent. It is the default for Writing items.

## Highlight effects

Override `getHighlightCss` in a Material Description to draw more attention to the items that can be moved, with `floatEffect`, `breatheEffect`, `glowEffect` or `glowFloatEffect`.

## Other improvements

- Drop areas are disabled when the dragged item cannot be dropped there.
- Items laid on a face of their parent turn with it.
- The `usePlayerUser` hook gives access to the real avatar of a player.
- The dev tools can replay the current game.
