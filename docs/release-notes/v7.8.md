# Release notes v7.8

## Game options in the game state

The options a game was set up with are recorded in the game state: read `this.game.options` in the rules instead of copying them into the memory. The field is absent from games created before this version.

## Fixes

- Drag and drop no longer gets stuck, and works again on old iPads.
- The tutorial no longer freezes when the pass button is clicked repeatedly.
- The history replay no longer crashes.
