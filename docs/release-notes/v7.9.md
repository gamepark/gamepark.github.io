# Release notes v7.9

## Identities depending on an option

[`identities` accepts `requires`](features/game-options.md?id=player-identities): when the requirement does not hold, no identity is assigned and players are numbered.

## Animations

- A [trajectory can fade](features/configure-the-animations.md?id=trajectories) an item in and out: `.trajectory({ fade: { in: 0.2, out: 0.2 } })`.
- Waypoints keep the scale of the item.

## Money

`MaterialMoney.addMoney` accepts a `consolidate` option, to exchange small coins for bigger ones when money is gained.

## User interface

- `<Menu resultDialogDelay={3000}/>` sets how long the result dialog waits before it opens at the end of a game (10 seconds by default).
- New theme options lay out the help, result and message dialogs.
- Items that the hiding strategy should hide stay hidden on the table once the game is over.
